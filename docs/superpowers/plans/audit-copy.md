### Task 1: Copywriting Audit (The Editor)

**Skills to Apply:** 
- `writing-guidelines`
- `avoid-ai-writing`

**Scope:** 
Review the textual content across all components (`components/*.tsx` and `app/page.tsx`). Pay special attention to:
- Biographies (e.g., in `about.tsx`)
- Project descriptions (e.g., in `projects.tsx`)
- Call to actions (e.g., in `contact.tsx` and `hero.tsx`)

**Instructions:**
1. Read the code for these components.
2. Cross-reference the text with the `avoid-ai-writing` principles to ensure it doesn't sound like AI slop.
3. Apply `writing-guidelines` to ensure clarity and professional tone.
4. If you find any writing issues, fix them directly in the components and commit them (`fix(copy): rewrite generic text`).
5. Write a brief summary of your fixes to `docs/superpowers/plans/audit-copy-report.md`.
