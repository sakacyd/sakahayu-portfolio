### Task 2: UI & UX Design Audit (The Architect)

**Skills to Apply:** 
- `web-design-guidelines`
- `ui-ux-pro-max`
- `high-end-visual-design`
- `design-taste-frontend`

**Scope:** 
Review `globals.css` and all Shadcn/custom components in `components/*.tsx`.

**Instructions:**
1. Check for basic UI/UX flaws (contrast issues, spacing issues, unreadable font sizes).
2. Ensure the layout adheres to the `high-end-visual-design` principles.
3. Validate mobile responsiveness.
4. Do NOT ruin the mathematical Grid Centering of the Hero section, but verify its aesthetics.
5. If you find minor UI issues, fix them directly and commit (`fix(ui): perfect aesthetic details`). 
6. If you find major architectural issues, DO NOT FIX them immediately, but note them.
7. Write a brief summary of your findings and fixes to `docs/superpowers/plans/audit-ui-report.md`.
