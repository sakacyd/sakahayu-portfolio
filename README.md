# Sakahayu Pribadi - Portfolio

A premium, high-end "Renaissance Art" themed personal portfolio website built with Next.js, React, Tailwind CSS v4, and Shadcn UI.

## Features
- **Cinematic Design**: Features a Double-Bezel architecture and Editorial Split layouts.
- **Fluid Motion**: Scroll animations powered by `motion/react`.
- **Responsive Geometry**: Exact mathematical grid centering for flawless mobile and desktop views.
- **Static Export**: Fully optimized static HTML generation.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS v4
- Shadcn UI
- Framer Motion

## Development
```bash
npm install
npm run dev
```

## Deployment
This project is connected to Vercel and is automatically deployed upon pushing to the `master` branch.
